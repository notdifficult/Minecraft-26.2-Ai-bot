# Minecraft-26.2-Ai-bot
достаточно примитивный бот для общения в чате и выполнения простых команд по типу иди за мной, тп, защищайся, выброси все и тд


для продолжения работы с этим ботом потребуется

1 - скачать LM Studio

2 - скачать модель Pantheon-RP-1.6.1-12b-Nemo

2.1 - вы можете заменить модель, тогда в файле config.js замените на свою LLM_MODEL: 'тут'

3 - настройте и запустите LM Studio Server

4 - запустите сервер minecraft 26.1 или 26.2 (другие не проверял)

5 - запустите StartBot.bat

5.1 - если нужен другой айпи вбейте его в config.js SERVER_HOST: 'localhost'

6 - зайдите на сервер и используйте чат для общения
